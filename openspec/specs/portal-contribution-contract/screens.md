# Screens

The contract between portaliq and the apps that contribute to it renders on these portal screens.

- MijnZaken https://identity.conduction.nl/screens/board?id=portaliq/MijnZaken: the resident's case list, filled by contributing apps, including cases shared with a partner (cas-contrib-list, con-contributed-pages-render, dem-tnd-joint-case-partner)
- Zaak https://identity.conduction.nl/screens/board?id=portaliq/Zaak: the case page with status transitions, file uploads and contact moments (cas-detail, act-row-transition, act-file-upload-generic, dem-fr-case-contact-moments)
- MobielZaak https://identity.conduction.nl/screens/board?id=portaliq/MobielZaak: the case page on a phone (cas-detail)
- ZaakWooVerzoek https://identity.conduction.nl/screens/board?id=portaliq/ZaakWooVerzoek: the case page for a Woo request, with its contact moments (cas-detail, dem-fr-case-contact-moments)
- MeldingIndienen https://identity.conduction.nl/screens/board?id=portaliq/MeldingIndienen: the form that creates an object in a contributing app (act-create-object)
- MijnKind https://identity.conduction.nl/screens/board?id=portaliq/MijnKind: a guardian's view of their child, scoped by list membership (sib-learniq-gua-guardian-sees-the-child)
- MijnOverzicht https://identity.conduction.nl/screens/board?id=portaliq/MijnOverzicht: the overview page with blocks contributed by other apps (con-contributed-pages-render, con-contributed-blocks)
- ThemaOverzicht https://identity.conduction.nl/screens/board?id=portaliq/ThemaOverzicht: a theme page built from contributed pages and blocks (con-contributed-pages-render, con-contributed-blocks)
- PtZaaktypeWeergave https://identity.conduction.nl/screens/board?id=portaliq/PtZaaktypeWeergave: the admin settings for how a contributed case type shows in the portal (con-ui-config-v3)
- PtRegioportaal https://identity.conduction.nl/screens/board?id=portaliq/PtRegioportaal: the regional portal page where stackiq shares its catalogue (sib-stackiq-share-portal)
