# example-set-anouk-follows-woo Specification

## Purpose
The Zuiddrecht example set: Anouk Bakker follows the Lindelaan Woo case.

## Requirements

### Requirement: Anouk Bakker follows the Lindelaan Woo case

The Zuiddrecht fragment SHALL declare that the cast member Anouk Bakker follows the Woo case `woo-fietspad`, with notifications on.

#### Scenario: The case page shows its follower
- **GIVEN** the set is installed
- **WHEN** a handler opens the Lindelaan Woo case
- **THEN** the followers SHALL include Anouk Bakker, shown as AB
