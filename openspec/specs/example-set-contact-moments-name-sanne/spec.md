# example-set-contact-moments-name-sanne Specification

## Purpose
The Zuiddrecht example set: the contact moments on the Lindelaan Woo case name Sanne de Vries as their contact.

## Requirements

### Requirement: The Lindelaan moments name Sanne as their contact

The contact moments on `woo-fietspad` SHALL name Sanne de Vries's BRP person as their `contact`.

#### Scenario: Sanne's history
- **GIVEN** the set is installed
- **WHEN** a handler opens Sanne de Vries as a contact
- **THEN** her four contact moments about the Lindelaan request SHALL be listed
