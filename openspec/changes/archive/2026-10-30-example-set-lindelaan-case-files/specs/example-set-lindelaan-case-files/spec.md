# example-set-lindelaan-case-files

## ADDED Requirements

### Requirement: The Lindelaan case carries the seven documents under review

The Zuiddrecht fragment SHALL declare as the files of `woo-fietspad` the files of its seven information objects, each present beside the fragment.

#### Scenario: The documents tab
- **GIVEN** the set is installed
- **WHEN** a handler opens the Lindelaan case's documents
- **THEN** the seven documents SHALL be listed, four of them with a Woo verdict
